# Steam Mcp Suite

Steam Mcp Suite — an MCP server.

## Why

- Free, no API key required
- One build, six registry listings (MCP official, Smithery, mcp.so, Glama, PulseMCP)

## Install

```bash
npx -y steam-mcp-suite
```

## Registry listings

| Registry | URL |
|---|---|
| MCP official | https://registry.modelcontextprotocol.io/ |
| Smithery | https://smithery.ai/ |
| mcp.so | https://mcp.so/ |
| Glama | https://glama.ai/mcp/servers |
| PulseMCP | https://www.pulsemcp.com/ |
